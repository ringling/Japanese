友ともだちに イベントの ボランティアを たのみましょう。 — Ask a friend to volunteer at an event.

はい、何なんですか。 Yes, what is it?

今いま、日本にほんまつりで ヨサコイが おしえられる 人ひとを さがしてるんですが…おねがいできませんか。 We're looking for someone who can teach Yosakoi dance at Japan Festival… would you be able to help?

こちらこそ。 Likewise — happy to help.

Ex.2 — ルールを はっけんしましょう (p.66)

雨あめが ふったら、みどりホールに あつまって ください
V-たら — if / when … (conditional)
  • きます → きたら — if/when [people] come
  • ふります → ふったら — if it rains
  • おわります → おわったら — when [setup] finishes
  • わかりません → わからなかったら — if [the location] is not known
❶
人ひとが たくさん（きます → ______）、はやく うけつけを はじめます。
→きたら
If many people come, start reception early.
❷
イベントの じゅんびが（おわります → ______）、さいとうさんに れんらくします。
→おわったら
When the event preparation is done, contact Saito.
❸
いすや テーブルの 場所ばしょが（わかりません → ______）、さいとうさんに 聞きいて ください。
→わからなかったら
If you don't know where the chairs and tables are, please ask Saito.
