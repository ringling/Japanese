文法ぶんぽう — だい7か

1. N が V-(られ)る ＋ 人ひと — Potential ②

N が V-(られ)ます → N が V-(られ)る ＋ 人ひと
a person who can … (ability / skill)

Use the plain potential form in front of a noun to describe a person by what they can do. Each row: ます-form → potential (polite) → potential (plain, used before ひと).

  • はなします → はなせます → はなせる — speak → can speak (1グループ: -i → -e)
  • かきます → かけます → かける — write / draw → can write / draw (1グループ: -i → -e)
  • おしえます → おしえられます → おしえられる — teach → can teach (2グループ: + られ)
  • します → できます → できる — do → can do (3グループ: irregular)

Examples

パウロさんは 日本語にほんごが 話はなせます。→ 日本語にほんごが 話はなせる 人ひと Paolo can speak Japanese. → a person who can speak Japanese
A) フリオさんは 日本にほんの 歌うたが 教おしえられますか。
B) 日本にほんの 歌うたは 大好だいすきですが、教おしえられません。 A) Julio, can you teach Japanese songs? B) I love Japanese songs, but I can't teach them.
日本にほんの おどりが おどれる 人ひとを さがしています。 I'm looking for someone who can do Japanese dance.
日本祭にほんまつりで つうやくが できる 人ひとを だれか しりませんか。 Do you know anyone who can interpret at the Japan Festival?

2. S1 たら、S2 — Conditional ①

V-た ＋ ら、S2
if / when … → what one will do (request, suggestion, invitation)
  • きます → きたら — if (people) come
  • ふります → ふったら — if it rains
  • おわります → おわったら — when it finishes
  • わかりません → わからなかったら — if you don't know
  • 暑あつい → 暑あつかったら · 雨あめ → 雨あめだったら — い-adjective / noun

Examples

雨あめが ふったら、ホールで ぼんおどりを します。 If it rains, we'll do the bon dance in the hall.
人ひとが たくさん 来きたら、はやく 受付うけつけを はじめます。 If many people come, we'll start reception early.
A) かいじょうに わすれものが あったら、どうしますか。
B) わすれものは 全部ぜんぶ 受付うけつけに 持もっていって ください。 A) What do we do if something is left behind at the venue? B) Please take all lost items to reception.
かいじょうが 暑あつかったら、エアコンを つけましょう。 If the venue is hot, let's turn on the air conditioning.
あした 雨あめだったら、イベントは 中止ちゅうしです。 If it rains tomorrow, the event is cancelled.
カメラの 使つかいかたが わからなかったら、たなかさんに 聞きいて ください。 If you don't know how to use the camera, please ask Tanaka.

3-2 — ルールを はっけんしましょう。 (p.66)

雨あめが ふったら、みどりホールに あつまって ください。
V-たら — きます→きたら · ふります→ふったら · おわります→おわったら · わかりません→わからなかったら

れい: カメラの 使つかいかたが わからなかったら、たなかさんに 聞きいて ください。 — Example: If you don't know how to use the camera, please ask Tanaka.
